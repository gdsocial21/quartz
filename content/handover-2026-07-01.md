## 레슨 정리

### 막혔던 지점과 해결법

1. **Quartz v5 빌드 에러** (`Could not resolve "../../.quartz/plugins"`)
   - 원인: `.quartz/plugins` 폴더가 `.gitignore`에 막혀 있고, 각 플러그인이 git submodule로 인식됨
   - 해결: 각 플러그인 폴더의 `.git` 제거 → `git add -f` → 일반 파일로 커밋
   - 최종: CF Pages 빌드 대신 로컬 빌드 후 `public/` 폴더 직접 push

2. **CF Pages Retry가 옛날 커밋으로 실행**
   - 원인: Retry는 해당 배포 시점 커밋 기준
   - 해결: "Check your build settings" → 저장 → 새 배포 트리거

3. **git submodule 문제**
   - `160000` 모드 = submodule (빈 폴더로 clone됨)
   - `100644` 모드 = 일반 파일 (정상)
   - `git rm -rf --cached .quartz/` 후 `.git` 제거 → 재 add

4. **브라우저 자동번역이 한글 이름을 바꿈**
   - "이주현" → "두토현" 등으로 번역됨
   - 해결: 번역 기능 끄기 (실행취소 버튼)
